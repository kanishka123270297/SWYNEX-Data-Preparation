# SWYNEX Data Preparation – Power BI

## Internship Task 1: Data Preparation

This project was completed as part of my Power BI internship at SWYNEX Technologies.

### Objective
The objective of this task was to prepare and clean a logistics and delivery dataset so that it could be used effectively for analysis and reporting in Power BI.

### Tool Used
- Power BI Desktop
- Power Query

### Data Preparation Steps
The following transformations were performed in Power Query:

1. Promoted the first row as column headers.
2. Converted `Order Date` to the Date data type.
3. Converted numerical fields to appropriate numeric data types.
4. Removed duplicate order records.
5. Standardized `Region` values for consistency.
6. Trimmed unnecessary spaces from text fields.
7. Reviewed `Delivery Status` values for consistency.
8. Checked the dataset for data-quality issues before loading it into Power BI.

### Dataset
The dataset contains logistics and delivery information such as:
- Order ID
- Order Date
- Customer Name
- Product
- Category
- Region
- Shipping Method
- Delivery Status
- Delivery Days
- Sales
- Delivery Cost
- Profit

### Outcome
The cleaned dataset is ready for the next stages of Power BI analysis, including data modeling, DAX calculations, and dashboard development.
